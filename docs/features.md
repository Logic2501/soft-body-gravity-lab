## 当前默认参数

`重力 250 / μ 7 / 软体大小 62 / 边缘 0.05 / 弯曲 0.01 / 面积 0.005 / 形状 0.000 / 平滑 1.00 / 阻尼 0.2 / 恢复 0.04 / 摩擦 0.04`

## 明确不做 / 已知限制

- ⛔ 软体之间的物理碰撞：当前多软体可互相穿过。
- ⛔ 软体自碰撞：折叠边缘可能自交。
- ⛔ 后端、数据库、账号、参数持久化。
- ⛔ 自动截图视觉验收；视觉由用户确认。
- 多软体共享全局参数；每个软体有独立位置、速度和约束。
- 重置会丢弃附加软体，只保留一个默认软体。

## 回归清单

1. 默认参数加载与“恢复推荐参数”。
2. 暂停/继续、重置、软体数量。
3. `+` 占位排队、`−` 删除最早、大小滑块缩放全部。
4. 边缘拖拽、中心拖拽切换与释放。
5. 等势线开关、上下覆盖、参数变化后重算。
6. `npm test`；物理模型/碰撞/约束改动后再跑 `npm run test:deep`。
7. 双击 `index.html` 与 Pages 页面可加载。

## 本地 Git 找回流程

功能疑似被后续改动吞掉时：

```bash
git log --oneline --decorate
git log -S "关键字" -- src/ tests/ docs/
git show <commit>:src/app.js > /tmp/app.js.before
git diff <commit> -- src/ tests/
```

确认后按需恢复单个文件或片段；不要用 `git reset --hard` 或 force push 覆盖历史。恢复后在下方追加日志，并同步功能状态。
