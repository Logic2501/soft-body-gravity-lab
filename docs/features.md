## 当前默认参数

`重力 500 / 水滴大小 15 / 边缘质点数 8 / 边缘 0.010 / 弯曲 0.00 / 面积 0.0020 / 形状 0.000 / 平滑 1.00 / 阻尼 0.18 / 中心拖拽阻尼 20 / 恢复 0.02 / 摩擦 0.01`；无中心引力；自动水龙头默认关；默认边缘拖拽。

## 明确不做 / 已知限制

- ⛔ 软体自碰撞：同一水滴的折叠边缘可能自交；水滴之间已有段碰撞。
- ⛔ 后端、数据库、账号、参数持久化。
- ⛔ 自动截图视觉验收；视觉由用户确认。
- 合并是面积/动量守恒的圆形重建，不是拓扑并集；合并瞬间丢失原形变。
- 分裂后子水滴重新生成圆环，丢失父体局部形状；颜色沿用固定浅蓝。
- 自动水龙头通常只形成大水滴，临界分裂主要靠拖拽/强碰撞触发。
- 边缘拖拽用抓取点 ±3 邻居加权、提高上限来接近中心拖拽体感，但两者不是完全同力。
- 上限 32 滴；自动发射 1 秒/侧；合并/分裂检查 60 Hz。
- 重置恢复 6 滴，不保留合并/分裂历史。

## 回归清单

1. 默认参数加载与“恢复推荐参数”。
2. 暂停/继续、重置回 6 滴、合并/分离计数清零。
3. `+` 从水龙头手动发射、`−` 删除最早、大小滑块只影响新水滴、自动水龙头开关。
4. `A/←` 与 `D/→` 左右发射，长按连发；鼠标点击/长按水龙头连发；输入框聚焦时不触发。
5. 擦除模式点按/拖拽删除水滴；与拖拽模式互斥；暂停时可用。
6. 边缘/中心拖拽切换与释放；中心拖拽阻尼可调且不震荡。
7. 水滴靠近合并：面积/动量守恒、质点数量按密度增加、冷却生效。
8. 临界形变分裂：纵横比/半径阈值、子体面积各半、边缘质点重连。
9. 边缘质点数改变后所有水滴重建、固定浅蓝保留、不炸。
10. 颜色固定浅蓝，不自动循环；合并/分裂沿用同一颜色。
11. 等势线默认关闭；打开后只反映重力，开关与重算正常。
12. 大小滑块只影响新发射水滴；边缘拖拽的局部加权力可感知。
13. `npm test`；物理/碰撞/约束改动后再跑 `npm run test:deep`。
14. 双击 `index.html` 可加载；本分支不部署 Pages。
