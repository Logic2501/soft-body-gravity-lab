## 架构

- 主交付：根目录静态 Web 单页，无后端、无构建步骤、无运行时依赖。
- `index.html` 可直接双击打开，也可由 GitHub Pages 托管。
- `src/soft_body_sim.js` 为浏览器与 Node 共用的物理求解器；`src/body_collisions.js` 处理水滴间边缘段碰撞与摩擦；`src/body_merge_split.js` 处理面积守恒合并、PCA 纵横比和临界分裂；`src/body_palette.js` 生成固定浅蓝色调色板；`src/app.js` 负责水龙头、合并/分离调度、Canvas、输入、UI 和等势能线。
- 本分支关闭中心引力，只保留向下重力；等势能线按 `Φ = −g·y` 绘制，10 px 网格 marching squares，参数变化时重算缓存。
- `native/` 为可选早期 Godot 4 版本，不参与 Web 部署。
- 仓库：https://github.com/Logic2501/soft-body-gravity-lab
- Pages：https://logic2501.github.io/soft-body-gravity-lab/
- `main` 与线上 Pages 保持原实验；本分支未合并、未推送、未部署。

## 已知问题

- 合并是圆形重建，不是拓扑并集；合并瞬间丢失原形变。
- 分裂子体重新生成圆环，丢失父体局部形状；颜色沿用固定浅蓝。
- 自动水流通常只形成大水滴；临界分裂主要靠拖拽/强碰撞触发。
- 单滴默认 8 质点；合并后按密度增加（8+8 约 12），大水滴仍可能离散。
- 边缘拖拽改为局部加权（±3 邻居）并提高上限，体感接近中心拖拽；仍非完全同力。
- 软体大小只影响新发射水滴，已有/合并水滴不缩放。
- 水龙头自动发射 1 秒/侧，手动连发 0.22 秒/滴，上限 32 滴；合并/分离检查 60 Hz；擦除按整个水滴删除。
- 同一水滴折叠处没有自碰撞，可自交；水滴之间已有边缘段碰撞。
- `native/` 仍为早期 8 参数版本，未同步本分支；其测试已冷归档。
- Canvas 像素比上限为 2；未做自动截图验收。
