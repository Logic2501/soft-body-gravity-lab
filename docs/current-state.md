## 架构

- 主交付：根目录静态 Web 单页，无后端、无构建步骤、无运行时依赖。
- `index.html` 可直接双击打开，也可由 GitHub Pages 托管。
- `src/soft_body_sim.js` 为浏览器与 Node 共用的物理求解器；`src/app.js` 负责 Canvas、输入、UI、固定步长循环和等势能线。
- 等势能线按总势能 `Φ = −g·y − μ/√(r²+ε²)` 绘制，10 px 网格 marching squares，参数变化时重算缓存。
- `native/` 为可选早期 Godot 4 版本，不参与 Web 部署。
- 仓库：https://github.com/Logic2501/soft-body-gravity-lab
- Pages：https://logic2501.github.io/soft-body-gravity-lab/
- `.github/workflows/pages.yml` 已部署到 GitHub Pages。

## 已知问题

- 中心引力单独作用时，对称圆形软体的压缩量较小；主要形变来自边界碰撞和轨迹变化。
- 默认值已拟合为 250 / 7 / 0.05 / 0.01 / 0.005 / 0.000 / 1.00 / 0.2 / 0.04 / 0.04；面积保持使用 0–0.05、形状保持使用 0–0.01，步进均为 0.001 的细调区间。把边缘、弯曲、面积保持都调到 0 时可能塌陷/翻转，属预期。
- 最终默认参数更新后未重跑数值测试。
- 轮廓折痕越尖锐，32 质点环的离散感越明显。
- `native/` 仍为早期 8 参数版本，未同步弯曲和轮廓平滑。
- Canvas 像素比上限为 2。
- 视觉效果、拖拽手感、等势能线密度和面板排版尚未由用户人工确认；未做自动截图验收。
