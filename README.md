# softBody

> 共享工具链：`~/Documents/RooPlayground/README.md`

## 概览

单个 2D 软体在向下重力、软化中心引力、惯性与封闭边界碰撞下的实时形变实验。

- 仓库：https://github.com/Logic2501/soft-body-gravity-lab
- GitHub Pages 入口：https://logic2501.github.io/soft-body-gravity-lab/
- 原型：https://logic2501.github.io/soft-body-gravity-lab/prototype/
- 水流版：https://logic2501.github.io/soft-body-gravity-lab/water/

主交付是**纯静态 Web 单页**：无后端、无构建步骤、无运行时依赖。双击 `index.html` 即可运行，也可以直接部署到 GitHub Pages。另在 `native/` 保留同源 Godot 4 版本作为可选原生实现。

## 运行

- 直接双击根目录 `index.html`（推荐，Chrome / Edge / Safari / Firefox 均可）。
- 可选本地服务器（仅用于手机或其他设备访问）：
  ```bash
  python3 -m http.server 8000
  ```
  然后访问 `http://localhost:8000/`。
- 不需要 `npm install`，不需要打包。

## GitHub Pages

Pages 只有一个站点，根路径是极简入口：

- `/`：选择“软体引力原型”或“软体水流版”
- `/prototype/`：`main` 分支的原型
- `/water/`：`feat/merge-split-water` 分支的水流版

`.github/workflows/pages.yml` 在同一次构建中分别 checkout `main` 和 `feat/merge-split-water`，组合出上述目录后通过 GitHub Actions 部署。水流版入口带高亮 `NEW` 角标。

推送 `main` 会自动更新整个站点；水流分支更新后，从 `main` 手动运行 workflow 即可刷新 `/water/`。feature branch 不直接作为部署 ref，避免 `github-pages` 环境保护规则拦截。

本地双击根目录 `index.html` 仍然是原型；入口页只在 Pages 构建中生成。

## 操作

- 拖拽模式按钮在“边缘”和“中心”之间切换：边缘是最近质点的局部拖拽；中心是对整个软体施加同向有限加速度。
- `+` 添加软体：默认出生点被占用时排队，空出后自动加入；`−` 从最早添加的软体开始删除。
- “软体大小”滑块同时缩放所有软体，新增软体也使用当前大小。
- `空格`：暂停/继续。
- `R` / “重置实验”：清空附加软体，恢复 1 个默认软体，保留当前参数。
- 右侧面板：13 个参数均为滑块 + 数值框双向同步；每行带 `?` 帮助标记，悬停、聚焦或点按即可在下方看到通俗说明；非法或越界输入自动还原。
- 边缘质点数改变会按当前圆心和大小重建所有软体；每个新软体颜色沿固定色相方向连续偏移。
- “重置实验”和“恢复推荐参数”是两个独立操作：前者重置运动，后者恢复参数。
- “显示质点与弹簧”：显示相邻、弯曲和径向约束。
- “显示等势能线”：默认开启，显示重力与中心引力叠加后的总势能等值线；可随时关闭。

## 物理模型

- 32 个轮廓质点，固定 240 Hz 步长；浏览器用时间累加器驱动，每帧最多补 24 步。
- 每步 6 次约束迭代：相邻距离、隔点弯曲、Shoelace 有符号面积、弱径向形状约束。
- PBD：先由外力预测位置，再修正约束，最后由修正后位置反推速度。
- 重力与中心引力逐质点施加：
  `a_center = μ · (center − p) / (|center − p|² + ε²)^1.5`，ε = 70 px，中心加速度上限 9000 px/s²。
- 每步按 `exp(−damping·dt)` 衰减速度，最大速度 2600 px/s。
- 墙壁位置投影 + 法向恢复系数 + 切向摩擦；低速接触时法向速度归零。
- 边缘模式抓最近轮廓点，中心模式对整体质心施加有限加速度，并带半临界阻尼（默认 20、可调）抑制震荡；上限均为 22000 px/s²，不瞬移。
- 可同时存在多个软体，共享全局参数；每个软体独立求解，边缘质点数 12–32（默认 16）。
- 软体之间用边缘段-段碰撞：2 px 安全边距、最近点法线方向分离、移除接近法向速度，切向摩擦沿用边界摩擦；每步 3 次迭代。当前不做同一软体的自碰撞。
- 新软体颜色按 HSL 固定方向 `+18°` 偏移（基准 156°），约 20 个软体遍历色相空间；缩放/重建保留颜色，重置回基准色。
- 轮廓用 Catmull-Rom 插值 + 一次拉普拉斯平滑绘制；形变来自质点位置，不使用整体缩放。
- 等势能线使用总势能 `Φ = −g·y − μ/√(r²+ε²)`，在 10 px 网格上用 marching squares 生成；等级取总势能按面积分位数均匀分布，避免混合等级造成近邻线和局部空白；重力、μ 或 ε 变化时重算并缓存。

## 推荐参数

| 参数 | 默认值 | 直观作用 | 范围 |
|---|---:|---|---|
| 重力强度 | 250 px/s² | 向下基础加速度 | 0–2500 |
| 中心引力 μ | 7 ×10⁶ px³/s² | 指向中心的引力强度 | 0–250 |
| 软体大小 | 62 px | 同时缩放所有软体；新增软体沿用 | 30–120 |
| 边缘质点数 | 16 | 轮廓质点数量；改变时重建所有软体 | 12–32，步进 2 |
| 边缘刚度 | 0.05 | 相邻质点距离约束；越低越容易拉伸/折叠 | 0–1 |
| 弯曲刚度 | 0.01 | 隔点约束，抵抗折角；0 允许折叠 | 0–0.20 |
| 面积保持 | 0.005 | 维持轮廓总面积；0 允许大幅收缩 | 0–0.05，步进 0.001 |
| 形状保持 | 0.000 | 拉回初始半径；0 完全自由 | 0–0.01，步进 0.001 |
| 轮廓平滑 | 1.00 | 仅影响绘制；0 显示尖锐折痕 | 0–1 |
| 阻尼 | 0.2 1/s | 速度衰减；越低振荡越久 | 0–8 |
| 中心拖拽阻尼 | 20 | 中心拖拽稳定性；越大越稳、越小越跟手 | 0–80 |
| 边界恢复 | 0.04 | 撞墙法向反弹比例 | 0–1 |
| 边界摩擦 | 0.04 | 撞墙切向速度损失 | 0–1 |

建议调节顺序：先调重力和中心引力观察轨迹；再调边缘刚度、弯曲刚度、面积保持和形状保持观察挤压/折叠；然后把轮廓平滑降到 0 附近观察真实折痕；最后用阻尼控制振荡、用边界恢复/摩擦控制撞墙手感。每次对比前可“重置实验”，参数不会被重置。

### 为什么“0.05”仍然不软

PBD 的滑块值是**每轮迭代**的修正比例，当前每步迭代 6 次。`0.05` 的等效修正约为 `1−(1−0.05)^6 ≈ 26%`；`0.005` 的面积约束约为 `3%`；`0.01` 的弯曲约束约为 `6%`。于是看起来“数值已经很小”，实际仍不软。边缘和弯曲下限已开放到 0，轮廓平滑也可调。

面积保持使用 `0–0.05`、步进 `0.001`；形状保持使用 `0–0.01`、步进 `0.001`。`0` 表示完全不约束，`0.001` 起就会持续恢复，所以 0 与 0.01 的差异是“无约束”与“持续约束”的定性差异。

要得到更极端的挤压/折叠：先降弯曲到 0，再把边缘降到 0.01–0.00，必要时把面积保持降到 0.001–0.000，形状保持降到 0.000；轮廓平滑调到 0–0.1 显示折痕。面积保持是防止整体塌陷的最后约束，完全关掉后软体可能收成一条或自交，这是预期实验现象。

如果还需要更接近真实软材料，而不只是“关约束”，下一步可改用 XPBD 柔度（compliance）或加入“面积下限 + 自碰撞”；当前版本没有实现这两项。

## 已验证行为（数值，非视觉）

```bash
npm test            # 快速核心 + UI
npm run test:deep   # 追加 20s 稳定性、默认参数长跑、可重复性、极端参数
```

最近完整测试通过：

- 自由落体：1 秒内质心从 y=190 下移到 y=587；4 秒内触底，无穿透。
- 单独中心引力（μ=90×10⁶）：1.2 秒内质心到源距离从 304.8 降到 154.0；无 NaN。
- 近距离中心：μ=250×10⁶ 运行 6 秒，加速度上限 9000 生效，无爆飞。
- 双力场压力场景（g=900、μ=90×10⁶）20 秒：最大径向偏差 98.5%、面积误差 32.1%、纵横比 2.80、最大速度 1546 px/s；无穿透、无翻转。
- 当前默认参数（16 质点半长）20 秒：最大径向偏差 42.6%、面积误差 17.3%、纵横比 2.38、最大速度 685 px/s；无穿透、无翻转。
- 边界碰撞（恢复系数 0.9、加强约束的隔离场景）：质心回弹约 81 px。
- 边缘拖拽：0.45 秒位移约 141 px；中心拖拽 1.4 秒后贴近目标、残余速度接近 0，无明显震荡。
- 软体间碰撞：初始重叠的两个软体分离，最小边缘距离从 0 增至约 91 px；持续 0.5 秒后不回落穿透。
- 软体间切向摩擦沿用边界摩擦：测试中切向速度从 120 降到 114。
- 质点数 16 重建稳定；色相序列 `156 → 174 → … → 156` 按固定方向循环。
- 20 秒内无 NaN/爆飞；重置与同初始状态重复运行位置差为 0。
- 极端参数：约束全关时无 NaN、无穿透，速度/中心加速度上限生效；软体可塌陷/翻转，属预期。

浏览器 UI 测试通过：13 个参数行、帮助说明、双向同步、非法输入还原、越界钳制、暂停/继续、重置、恢复默认、软体添加排队、删除最早、大小缩放全部、质点数重建、色相序列、中心拖拽阻尼、边缘/中心拖拽切换、等势线开关；固定场参数下生成 14 条等势线、约 1648 个线段，纵向覆盖 y=56–733。

## 待用户视觉确认

- 默认边缘刚度/面积保持下的果冻观感、挤压幅度与回弹速度。
- 中心引力单独作用时，圆形软体的对称压缩是否足够明显（数值上形变主要来自碰撞和轨迹变化）。
- 轮廓粗细、分层填充、边缘亮线和面板排版在真实浏览器中的可读性。
- 鼠标/触摸拖拽的局部凹陷是否足够明显。
- 等势能线的密度、透明度和是否干扰软体观察；可关闭。
- 手机窄屏下的布局与触控手感。

## 已知问题

- 中心引力场对完全对称的圆形软体主要产生均匀压缩，单独开启时形变不如边界碰撞明显。
- 把边缘、弯曲、面积保持都调到 0 时，软体可能收成一条、塌陷或翻转；默认参数稳定，这是主动关闭形状约束的预期结果。
- 软体自身折叠处目前没有自碰撞，可自交；软体之间已有边缘段碰撞。
- 轮廓折痕越尖锐，32 质点环的离散感越明显；必要时可提高质点数或降低轮廓平滑。
- Web 版 Canvas 像素比上限为 2，极高分屏不会按 3x/4x 渲染。
- 尚未进行自动截图或人工视觉验收；视觉项均以“待用户确认”记录。
