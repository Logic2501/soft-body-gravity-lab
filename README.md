# softBody（水流合并 / 临界分离分支）

> 共享工具链：`~/Documents/RooPlayground/README.md`

## 概览

实验分支：大量 8 质点小水滴在重力、封闭边界和左右两个水龙头之间流动；靠近自动合并，形变超过临界值自动分离。

- 分支：`feat/merge-split-water`（本地实验分支，未合并、未推送）
- 仓库：https://github.com/Logic2501/soft-body-gravity-lab
- Pages：`main` 仍部署原实验；本分支未部署

主交付仍是**纯静态 Web 单页**：无后端、无构建步骤、无运行时依赖。双击 `index.html` 即可运行。`native/` 保留同源 Godot 4 版本作为可选实现，本分支未同步。

本分支相对 `main` 的差异：

- 关闭中心引力，只保留向下重力。
- 默认水滴大小 22 px、8 个边缘质点；上限 32 滴。
- 左右下角各一个水龙头，自动/手动中心拖拽发射。
- 水滴靠近合并；合并体面积守恒，颜色取来源之一。
- 合并体或水滴的协方差纵横比超过 `2.6`、半径至少 `28` 且冷却结束时，分裂成两个面积相等的子水滴，边缘质点重新连接。
- 初始 6 滴，自动水龙头默认开启。

## 运行

- 直接双击根目录 `index.html`（推荐，Chrome / Edge / Safari / Firefox 均可）。
- 可选本地服务器（仅用于手机或其他设备访问）：
  ```bash
  python3 -m http.server 8000
  ```
  然后访问 `http://localhost:8000/`。
- 不需要 `npm install`，不需要打包。

## 操作

- 拖拽模式默认“中心”：抓取水滴质心可整体拖动；切到“边缘”可拉出局部凹陷。
- `+` 从下一侧水龙头手动发射一滴；`−` 删除最早的水滴。
- “自动水龙头”默认开启：左右水龙头每 1 秒各发射一滴，达到 32 滴上限后停止新增。
- 重置实验清空并恢复底部中央的 6 滴初始水，重置合并/分离计数；不改变当前参数和自动水龙头开关。
- 右侧面板：12 个参数均为滑块 + 数值框双向同步；非法或越界输入自动还原。
- 水滴靠近到约 18 px 边缘间隙时合并；合并体面积守恒、速度按面积加权。
- 合并体纵横比达到 `2.6`、半径至少 `28 px` 且冷却结束时，自动分裂成两个面积相等的子水滴；子水滴重新生成闭合边缘质点。
- “显示等势能线”显示纯重力势能线；本分支没有中心引力。
- 空格暂停/继续；`R` 重置。

## 物理模型

- 默认 8 个轮廓质点，固定 240 Hz 步长；每帧最多补 24 步。核心求解器仍保留 32 质点压力测试。
- 每步 6 次约束迭代：相邻距离、隔点弯曲、Shoelace 有符号面积、弱径向形状约束。
- PBD：先由外力预测位置，再修正约束，最后由修正后位置反推速度。
- 本分支关闭中心引力，只保留向下重力；势能线也只显示 `Φ = −g·y`。
- 每步按 `exp(−damping·dt)` 衰减速度，最大速度 2600 px/s；墙壁位置投影 + 恢复系数 + 切向摩擦。
- 水滴之间用边缘段-段碰撞：2 px 安全边距、法向分离、切向摩擦沿用边界摩擦；每步 3 次迭代。
- 合并：包围圆粗筛后检查边缘间隙 ≤ 18 px；合并体面积取两者面积之和，质心/速度按面积加权；边缘质点数量取两者较大值，重新生成闭合圆环；合并后 0.55 s 内不再合并。
- 分裂：用位置协方差的特征值比得到纵横比；半径 ≥ 28 px、纵横比 ≥ 2.6、冷却结束且稳定 0.8 s 后，按主轴分成两个面积相等的子水滴，子水滴重新生成闭合边缘质点并带轻微分离速度。
- 水龙头：左右下角各一个；自动模式每 1 秒各发射一滴，上限 32 滴；发射使用中心拖拽力，目标指向画面中心，持续 0.34 s 后释放。
- 初始 6 滴位于底部中央；重置会恢复这 6 滴并清空合并/分离计数。
- 新水滴颜色按 HSL 固定方向 `+18°` 偏移（基准 156°）；合并/分裂沿用来源颜色。
- 轮廓用 Catmull-Rom 插值 + 一次拉普拉斯平滑绘制。
- 等势能线只按重力势能在 10 px 网格上生成；重力变化时重算并缓存。

## 推荐参数

| 参数 | 默认值 | 直观作用 | 范围 |
|---|---:|---|---|
| 重力强度 | 500 px/s² | 向下基础加速度 | 0–2500 |
| 软体大小 | 22 px | 同时缩放所有水滴；新增水滴沿用 | 10–60 |
| 边缘质点数 | 8 | 单个水滴的轮廓质点数；改变时重建全部 | 8–24，步进 2 |
| 边缘刚度 | 0.02 | 相邻质点距离约束；很低以利于流动 | 0–1 |
| 弯曲刚度 | 0.00 | 隔点约束；0 完全允许折角 | 0–0.20 |
| 面积保持 | 0.001 | 维持大面积；很低以允许挤压 | 0–0.05，步进 0.001 |
| 形状保持 | 0.000 | 拉回圆形；0 完全自由 | 0–0.01，步进 0.001 |
| 轮廓平滑 | 1.00 | 仅影响绘制 | 0–1 |
| 阻尼 | 0.18 1/s | 速度衰减 | 0–8 |
| 中心拖拽阻尼 | 20 | 拖拽稳定；发射时临时提高到 50 | 0–80 |
| 边界恢复 | 0.02 | 撞墙法向反弹 | 0–1 |
| 边界摩擦 | 0.01 | 撞墙切向速度损失 | 0–1 |

这是“软水”预设：边缘距离、弯曲、面积和形状约束都压得很低，水滴容易挤压、拉长和合并。`0` 表示完全不约束；把面积和边缘都关掉后可能塌陷/自交，属于预期实验现象。

如果还需要更接近真实软材料，而不只是“关约束”，下一步可改用 XPBD 柔度（compliance）或加入“面积下限 + 自碰撞”；当前版本没有实现这两项。

## 已验证行为（数值，非视觉）

```bash
npm test            # 快速核心 + 水流合并/分裂 + UI
npm run test:deep   # 追加 20s 稳定性、默认参数长跑、可重复性、极端参数
npm run test:water  # 只跑水流合并/分裂专项
```

最近完整测试通过：

- 核心物理：自由落体、中心引力、双力场、边界回弹仍通过；速度为上限内，无穿透。
- 软体间碰撞：初始重叠的两个软体分离，最小边缘距离从 0 增至约 79 px；0.5 秒后仍约 103 px，不回落穿透。
- 软体间切向摩擦沿用边界摩擦：切向速度从 120 降到 114。
- 合并：两个 8 质点水滴合并后仍为 8 质点；面积 `2737.9 → 2737.9`，面积加权质心 `(310,300)`、速度 `10 px/s`。
- 分裂：纵横比 `10.0` 的 80 px 水滴分成两个 8 质点子水滴；面积 `18101.9 → 18101.9`，两子体中心距约 `90.5 px`，分离速度 `150 px/s`。
- 软水单滴 12 秒：无 NaN、无穿墙。
- 浏览器水流：3.5 秒自动水龙头场景产生 `9` 次合并、`4` 个水滴；强制把最大水滴拉伸到临界值后产生 `1` 次分裂，水滴数 `3 → 4`。
- UI：12 个参数行、2 个水龙头、初始 6 滴/上限 32、自动水龙头开关、双向同步、非法输入还原、暂停/继续、重置、大小缩放、质点数重建、色相、中心拖拽阻尼、拖拽模式、等势线；等势线 14 级、约 1204 段，纵向覆盖 y=73–707。

## 待用户视觉确认

- 8 质点小水滴的“水感”、软度、合并速度和大水滴形态。
- 左右水龙头弧线是否自然，是否会把水甩到角落。
- 临界分裂的触发频率；默认自动水流通常不分裂，需要拖拽或强挤压才明显。
- 大水滴半径 98 px 时 8 质点的轮廓是否足够平滑。
- 面板 12 行参数与新增“自动水龙头”开关的排版。
- 手机窄屏下的布局与触控手感。

## 已知问题

- 合并是面积/动量守恒的“圆形重建”，不是真正的拓扑并集；合并瞬间会丢失原形变。
- 分裂后子水滴是重新连接的圆环，会丢失父体局部形状；颜色沿用来源。
- 自动水流通常只形成大水滴，不一定自然达到分裂阈值；分裂主要靠用户中心/边缘拖拽或强碰撞触发。
- 同一水滴的折叠边缘仍无自碰撞，可自交；水滴之间已有边缘段碰撞。
- 默认 8 质点在大水滴上离散感明显；可把边缘质点数临时提高到 16–24。
- 自动水龙头上限 32 滴；合并/分裂检查以 60 Hz 运行，碰撞仍为 240 Hz。
- Web 版 Canvas 像素比上限为 2，极高分屏不会按 3x/4x 渲染。
- 尚未进行自动截图或人工视觉验收；视觉项均以“待用户确认”记录。
